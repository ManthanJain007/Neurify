## 🐛 Troubleshooting

### Common Issues

#### "AI Not Ready" Status
**Problem**: The extension shows "AI Not Ready" in the popup.

**Solutions**:
1. Ensure you're using Chrome 120 or later
2. Enable Chrome AI features:
   - Go to `chrome://flags/`
   - Enable "Prompt API for Gemini Nano" and "Summarization API for Gemini Nano"
   - Restart Chrome
3. Clear extension data and reload

#### Extension Not Working on Certain Sites
**Problem**: The floating toolbar doesn't appear on some websites.

**Solutions**:
1. Check if the site is in your blocked sites list (Options → Advanced)
2. Some sites may block content scripts - this is expected behavior
3. Try refreshing the page after enabling the extension

#### Performance Issues
**Problem**: Slow text analysis or high CPU usage.

**Solutions**:
1. Increase the analysis delay in Options → AI Settings
2. Reduce suggestion intensity to "Conservative"
3. Disable unused features in Options → Features

#### Suggestions Not Appearing
**Problem**: No grammar or style suggestions are shown.

**Solutions**:
1. Ensure the extension is enabled (green status in popup)
2. Check that relevant features are enabled in settings
3. Try switching modes (Auto mode enables all features)
4. Verify the text field is supported (works best with textareas and contenteditable elements)

### Getting Help

If you encounter issues not covered here:

1. **Check the Console**: Open Chrome DevTools (F12) and look for error messages
2. **Reset Settings**: Use "Reset to Defaults" in the Options page
3. **Clear Data**: Use "Clear All Data" in Options → Advanced (this will reset everything)
4. **Report Issues**: Create an issue on the GitHub repository with:
   - Chrome version
   - Extension version
   - Steps to reproduce the problem
   - Any console error messages
