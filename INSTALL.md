# 🚀 AI Writing Assistant Pro - Installation Guide

## Quick Setup (5 minutes)

### Step 1: Get Your Free Gemini API Key
1. Visit [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click **"Create API Key"** 
4. Copy the generated key (keep it safe!)

### Step 2: Install the Extension
1. **Download** this project or clone the repository
2. **Open Chrome** and navigate to `chrome://extensions/`
3. **Enable "Developer Mode"** (toggle in top-right corner)
4. Click **"Load unpacked"** 
5. **Select** the `ai-writing-assistant` folder
6. **Pin** the extension to your toolbar (✨ icon)

### Step 3: Configure Your Settings
1. **Click** the extension icon ✨ in your toolbar
2. **Enter** your Gemini API key in the settings
3. **Choose** your preferred writing mode and tone
4. **Customize** features in the advanced settings

### Step 4: Start Writing!
1. **Go to any website** with text fields (Gmail, Google Docs, etc.)
2. **Click in a text area** - the floating toolbar appears
3. **Start typing** - get real-time suggestions instantly!

## 🛠️ Troubleshooting

### ❌ "API Key Required" Error
**Solution:**
1. Get API key from [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Paste in extension settings (gear icon)
3. Wait for green "API Ready" status

### ❌ "Connection Failed" Error  
**Causes & Solutions:**
- **Internet connection**: Check your connection
- **Firewall/Proxy**: Allow connections to `generativelanguage.googleapis.com`
- **API key issues**: Regenerate key in Google AI Studio
- **Rate limits**: Wait a moment and try again

### ❌ Floating Toolbar Not Appearing
**Solutions:**
1. **Check if enabled**: Extension popup → ensure toggle is ON
2. **Reload page**: Refresh the webpage you're on
3. **Compatible sites**: Works on most sites, some may block it
4. **Re-install**: Remove and re-add the extension

### ❌ No Suggestions Appearing
**Check these settings:**
1. **Mode selection**: Choose "Auto" or "Grammar Check" mode
2. **Feature toggles**: Enable "Real-time Analysis"
3. **Text length**: Type at least a few words
4. **Site compatibility**: Try on Gmail or Google Docs first

## ⚙️ Advanced Configuration

### Custom Dictionary Setup
1. Open **Options page** (Right-click extension → Options)
2. Go to **Personalization** section
3. Add custom words, brand names, technical terms
4. One word per line in the text area

### Site-Specific Rules
1. **Allowed Sites**: Leave empty for all sites, or add specific domains
2. **Blocked Sites**: Add sites where you don't want the extension
3. Use wildcards: `*.example.com` for all subdomains

### Privacy Settings
- **Local Processing**: Prefer local analysis when possible
- **Analytics**: Disable to prevent usage data collection
- **Data Management**: Export/import settings, clear data

## 📊 Performance Optimization

### For Best Performance:
1. **Close unused tabs** to free up memory
2. **Use "Conservative" intensity** for slower devices
3. **Disable unused features** in settings
4. **Clear extension data** occasionally (Options → Clear Data)

### Battery Saving (Laptops):
1. Set analysis delay to **500ms** instead of 300ms
2. Disable **real-time analysis** for casual browsing
3. Use **Quick Fix** mode instead of Auto mode

## 🔒 Privacy & Security

### Data Handling
- **API Key**: Stored locally in Chrome, never shared
- **Text Analysis**: Sent to Google Gemini API over HTTPS
- **Settings**: Synced via Chrome's secure sync service
- **No Tracking**: No analytics unless you opt-in

### Best Practices
1. **Don't share** your API key with others
2. **Review settings** before enabling analytics
3. **Use site blocking** for sensitive websites
4. **Regular updates**: Keep extension updated
